# One World · One Day — 18 November 2026

A single-image summary of Wednesday 18 November 2026, laid out as the front page
of a broadsheet: a red rule and masthead, a prominent dateline, one lead story
and a 2×3 grid of six more, each with a serif headline, a one-line dek and a flat
SVG pictogram. Newsprint paper (`#f3eee3`), black ink (`#17130e`), one accent red
(`#b31b1b`), Georgia headlines over a Helvetica dek — FT/Economist front-page
register rather than a dashboard.

The poster itself (`entry.png`, 1024×1024) is committed to the repo so the
program needs no browser, no fonts beyond the system set and no network.

## Stories on the page

- **Lead** — Trump lands in Shenzhen as Xi and Putin huddle (APEC; first US–China–Russia trilateral)
- Iran strikes Kuwait and Bahrain
- Peltola flips Alaska, sealing a Democratic Senate rout
- Nvidia's $116bn quarter fails to lift shares
- Voyager 1 reaches one light-day from Earth
- Bezos: I was 'heavily involved' in picking the new Bond
- MS Dhoni retires from IPL cricket

## Run

```bash
python3 main.py
```

Copies `entry.png` to `/output/entry.png`. Deterministic: two runs produce
byte-identical output. Standard library only.

## Files

- `entry.png` — the rendered poster (1024×1024, RGB PNG)
- `poster.html` — the source layout that produced it (open in a browser at 1024×1024)
- `main.py` — the grader entry point
